# Amazon-Review
Amazon-Review project sees your review and rates it , A naive Bayes Multinominal Algorithm that learns from previous data and rates the user custom review
From 1-5 with an accuracy of : 74.29%

# How is it used 

You the user write a custom message ( Review ) 
and pass the function ```valueOfReview``` and for parameters you pass (Msg, ```ratingKey```)

# Tools used

```Python```
```Scikit-learn```
